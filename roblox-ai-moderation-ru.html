Модерация чата в Roblox нейросетью — по смыслу

Списочный фильтр обходят за секунду: опечатка, пробел между букв, эвфемизм — и токсичность проходит, а безобидное «assassin» блокируется. Нейросеть смотрит на смысл целиком.

Один серверный запрос

local Cortex = require(game.ServerStorage.Cortex)
local ai = Cortex.new("ТВОЙ_КЛЮЧ")

local verdict = ai:ask(
  "Ты модератор детской игры. Ответь одним словом: SAFE или BLOCK.",
  message
)
if verdict == "BLOCK" then --[[ не пропускать ]] end

ИИ ловит завуалированную токсичность и обход фильтра, а безобидные фразы с «плохими» подстроками пропускает. Ключ на сервере, оплата робуксами.

Это почти бесплатно

Ответ модерации — одно слово, а Cortex платит только за выход: проверка сообщения стоит доли юнита, повторы из кэша даром. 25 юнитов = 1 робукс (юнит = 1000 выходных токенов). Модерировать можно хоть весь чат.

🎁 Открытая бета — бесплатные ключи первым девам. Ранние тестеры сохраняют вечную founder-скидку + награду робуксами за запуск с обратной связью.
